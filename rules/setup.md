# Setup Rules

This document defines the current setup rules for the first playable prototype of Shopkeeper Showdown.

These rules are for Version 0.1.2 and are intended to make the game playable for testing. They may change after playtesting.

---

## 1. Game Length

The game lasts **3 rounds**.

Each round follows this structure:

1. Adventure Phase
2. Town Phase
3. Selling Phase
4. Cleanup

The game ends after the Selling Phase of Round 3.

---

## 2. Player Count

The current prototype supports **2–6 players**.

For the first playtest, the recommended player count is **2–4 players** so the core systems can be tested more easily.

---

## 3. Shared Setup

Place the following in the centre of the table:

* Adventure board
* Town board
* Resource Deck
* Crafted Goods Deck
* Adventure Deck
* Selling Card Deck
* Coin supply
* Reputation supply or tracker
* Mystery Tokens
* Dice
* Round tracker
* First Player marker

Shuffle each deck separately.

---

## 4. Adventure Board Setup

Set up the Adventure board.

For the first prototype, the Adventure board uses **Mystery Tokens** to mark unknown points of interest.

At the start of the game, place Mystery Tokens on the Adventure board.

Current prototype rule:

* Place **2 Mystery Tokens per player** on the Adventure board.
* Mystery Tokens are placed randomly.
* If a Mystery Token would be placed on an occupied space, reroll or place it on the nearest empty valid space.

Mystery Tokens represent unknown Adventure encounters.

When a player reaches and interacts with a Mystery Token, they remove the token and reveal the top card of the Adventure Deck.

The revealed card may be:

* Monster
* Quest
* Trap
* Discovery

Players do not know what type of Adventure Card they will reveal before interacting with the Mystery Token.

---

## 5. Public Visitor Setup

Reveal **1 public Visitor Selling Card**.

This card represents the current shared customer available to all players.

Only Visitor-type Selling Cards should be used for the public Visitor slot.

The public Visitor is available during the Selling Phase. Players may sell to or complete the Visitor according to the Selling Phase rules.

If the public Visitor is completed, discard it and reveal a new Visitor Selling Card.

---

## 6. Player Setup

Each player starts with:

* 20 Coins
* 0 Reputation
* 0 Training
* 1d6 adventurer dice
* +1 to Adventure rolls
* 3 chosen private Orders
* 3 Order slots
* No shop upgrades
* No equipped gear unless a future setup rule says otherwise

---

## 7. Starting Resource Draft

Deal each player **5 Resource Cards**.

Each player chooses **3 Resource Cards** to keep and discards the remaining 2.

Kept cards are placed in that player’s inventory.

Discarded cards are placed in the Resource discard pile.

This gives each player a small starting inventory while allowing them to make an early strategic choice.

---

## 8. Starting Private Orders

Each player starts the game with 3 Order slots.

During setup, each player chooses 3 starting private Orders from the available private Order piles.

Players may choose which piles to draw from.

Example choices:

3 Visitor Orders
2 Craft Requests and 1 Hero Order
1 Business Order, 1 Luxury Commission, and 1 Black Market Deal

Each chosen Order is placed face up in that player’s shop.

These 3 Orders fill the player’s starting Order slots.

Do not use the earlier rule where players were dealt 3 Selling Cards and kept 2.

### Public Visitor Setup

Replace any old public Selling market wording with this:

Public Visitor Setup

Reveal 1 Public Visitor card and place it in the shared Public Visitor slot.

The Public Visitor is available to all players during the Selling Phase.

The Public Visitor is not completed like a private Order.

Instead, the Public Visitor buys eligible leftover goods after players have completed any private Orders they want to complete.

For the first prototype, use this Public Visitor:

The King
Buys: Trinkets or Armaments
Rate: Face value
Limit: 10 Coins per individual card

The Public Visitor remains in play until a rule or effect changes it.

---

## 9. Starting Adventurer Strength

Each player begins with a basic adventurer.

Current prototype rule:

* Starting adventurer dice: **1d6**
* Starting training: **0**
* Starting boons: none

Training during the Town Phase may improve the adventurer’s dice or unlock boons.

---

## 10. First Player

Choose a first player randomly.

Suggested methods:

* Roll a die. Highest roll becomes first player.
* The player who last bought something from a shop becomes first player.
* The player who most recently played a fantasy game becomes first player.

Give that player the First Player marker.

The First Player marker rotates during Cleanup.

---

## 11. Starting Game State Summary

Each player starts with:

| Starting Item         |              Amount |
| --------------------- | ------------------: |
| Coins                 |                  20 |
| Reputation            |                   0 |
| Training              |                   0 |
| Adventurer Dice       |                 1d6 |
| Resource Cards        | 3 kept from 5 dealt |
| Private Selling Cards | 2 kept from 3 dealt |
| Shop Upgrades         |                   0 |

The shared board starts with:

| Shared Area         | Setup                          |
| ------------------- | ------------------------------ |
| Adventure Board     | 2 Mystery Tokens per player    |
| Public Visitor      | 1 face-up Visitor Selling Card |
| Round Tracker       | Round 1                        |
| First Player Marker | Randomly assigned              |

---

## 12. Setup Design Notes

The starting resource and Selling Card drafts are intended to give players early direction without overwhelming them.

Players begin with **20 coins** so they have enough money to interact with Town actions, pay costs, recover from setbacks, and make early strategic choices without being locked out too quickly.

The public selling area starts with **1 Visitor** rather than a full market of public Selling Cards. This keeps the shared customer focus from the original game while still allowing private Selling Cards to guide each player’s personal strategy.

Players should begin Round 1 with enough information to make meaningful choices, but not enough to already know their entire strategy.

The starting setup should support different early paths, such as:

* Chasing resources needed for private Selling Cards
* Selling to the public Visitor
* Using Town actions to craft or upgrade
* Exploring Mystery Tokens for better rewards
* Training the adventurer for stronger Adventure rolls

These setup rules should be tested for pacing, fairness, and whether players can complete at least one meaningful sale in Round 1.
